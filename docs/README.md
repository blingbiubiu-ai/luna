# Documentation

Start with the [system overview](overview.md), follow the
[deployment guide](runbooks/deploy-luna.md) to run Luna, or use the
[release checklist](releasing.md) when preparing a distribution.

- `designs/`: current architecture, responsibilities, data flows and constraints.
- `runbooks/`: generic deployment and operational procedures.
- `local/`: private environment details, historical proposals and development
  records. This directory is ignored by Git and is not part of the public docs.

Public documentation is written in English. Examples use placeholders or
reserved example domains and addresses. Provider-neutral architecture belongs
here; deployment-specific plugin bundles and credentials belong in local files
or their external repositories.
